# 37・39号館 教室マップ

日本大学生産工学部 津田沼キャンパスの **37号館・39号館** について、令和8年度 学部時間割をもとに
1限〜6限の教室使用状況(空き / 授業あり)をフロアマップ上に表示する Web アプリです。

- 学期(1Q〜4Q)・曜日・時限を選ぶと、各階の教室が色分け表示されます
- 教室をタップすると、その日の1〜6限と1週間の使用状況を確認できます
- 「1〜6限 一覧」タブで建物全体の1日の使用状況を表形式で確認できます
- 「いま」ボタンで現在の学期・曜日・時限に戻ります

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体(ビルド不要の静的サイト) |
| `data/timetable.json` | 時間割Excelから生成した教室ごとの授業データ |
| `tools/build_data.py` | Excel → JSON 変換スクリプト |

## 時間割データの更新

```bash
pip install openpyxl
python tools/build_data.py "令和８年度時間割_学部.xlsx"
```

`data/timetable.json` が上書きされるので、コミットして push すれば GitHub Pages に反映されます。

## ローカルで確認

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます(`file://` で直接開くとデータを読み込めません)。

## 注意

- フロア図は第35回桜泉祭デジタルパンフレットの校内図を参考に作成した模式図です。
  37号館1階・8階、39号館6階はパンフレットに図がないため配置を推定しています。
- 集中講義や時限「その他」の授業は含みません。時限の時刻・クォーターの区切りは目安です。
